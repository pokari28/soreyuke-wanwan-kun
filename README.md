# それゆけワンワン君

外旭川わんわん保育園の保育クイズ（単体動作版）

- リポジトリ: https://github.com/pokari28/soreyuke-wanwan-kun
- 公開URL: https://pokari28.github.io/soreyuke-wanwan-kun/

## 遊び方
1. 基礎（10問）かプロ（30問）を選ぶ
2. 正解・不正解で先生の表情が変わる
3. 10 / 20 / 30 問連続正解でマイルストーン

## 公開
GitHub の Settings → Pages → Source を **GitHub Actions** にする。

初回だけ Actions タブでワークフロー許可が必要なことがあります。
