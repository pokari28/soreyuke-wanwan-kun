# それゆけワンワン君

外旭川わんわん保育園の保育クイズです。

リポジトリ: https://github.com/pokari28/soreyuke-wanwan-kun

## 遊び方

1. このリポジトリをクローンし、`index.html` をブラウザで開く
2. GitHub Pages で公開する場合
   - Settings → Pages
   - Source を GitHub Actions にする
   - 公開URL: https://pokari28.github.io/soreyuke-wanwan-kun/

## 画像の追加

キャラ画像は `assets/` に置いてください。

- beginner_idle.jpg / beginner_good.jpg / beginner_bad.jpg
- pro_idle.jpg / pro_idle_plus.jpg / pro_good.jpg / pro_bad.jpg
- milestone_10.jpg / milestone_20.jpg / milestone_30.jpg
- ending_perfect.jpg / title.jpg

GitHub の画面上で `Add file` → `Upload files` から `assets` フォルダへドラッグ＆ドロップできます。
